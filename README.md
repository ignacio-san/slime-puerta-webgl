# Slime y la Puerta (WebGL)

Videojuego 2D de plataformas hecho en Unity 6 como proyecto final del módulo *Programación de videojuegos*.

**Jugar:** https://ignacio-san.github.io/slime-puerta-webgl/

## Controles
- **A / D** o **flechas**: mover
- **Espacio**: saltar
- **J**: atacar
- Botón **Abrir puerta**: abre o cierra la puerta (activa el Animator y un Animation Event con sonido y partículas)

Build generada con Unity 6 (6000.6.10f1) para la plataforma Web (WebGL), sin compresión para que GitHub Pages la sirva directamente.
